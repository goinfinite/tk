Database connection management and query-building utilities. Package name: `tkInfraDb`.

## Summary

- model/ — GORM database model structs with ToEntity() transformations
- trailDatabaseService.go — SQLite database initialization and auto-migration for activity records (path from TRAIL_DATABASE_FILE_PATH env var)
- trailDatabaseService_test.go — tests for database service initialization
- transientDatabaseService.go — shared in-memory SQLite key-value store (Has, Read, Set); Set upserts, Read returns ErrKeyNotFound, and a failed count in Has logs and returns false; every instance in the process shares the same data through cache=shared
- transientDatabaseService_test.go — tests for the transient key-value store
- paginationQueryBuilder.go — builds paginated GORM queries (page-number and last-seen-id modes); callers MUST set `.Model(...)` because sort fields and the default cursor column resolve through the parsed schema; a caller-provided `primaryKeyColumn` is the quoted database column name, not schema-resolved
- paginationQueryBuilder_test.go — tests for pagination query building
- paginationPagesTotalResolver.go — exported pure page-count rule (PaginationPagesTotalResolver: reject zero page size via ErrItemsPerPageCannotBeZero, reject a count beyond uint32 via ErrPagesTotalOverflow, count a partial page as a page) usable outside GORM; the builder defers its page-count validation to it so the checks live in one place
- paginationPagesTotalResolver_test.go — tests for the page-count rule
