Database connection management and query-building utilities. Package name: `tkInfraDb`.

## Summary

- model/ — GORM database model structs with ToEntity() transformations
- trailDatabaseService.go — SQLite database initialization and auto-migration for activity records (path from TRAIL_DATABASE_FILE_PATH env var)
- trailDatabaseService_test.go — tests for database service initialization
- paginationQueryBuilder.go — builds paginated GORM queries from pagination DTOs (supports page-number and last-seen-id modes); callers MUST set `.Model(...)` on the query because the builder parses the statement schema; ORDER BY sort fields resolve through that schema (LookUpField), so camelCase maps to the real column and unknown fields fail with UnknownPaginationSortFieldError instead of invalid SQL; the last-seen-id cursor column defaults to the schema's prioritized primary key and is quoted through the statement so it cannot inject SQL
- paginationQueryBuilder_test.go — tests for pagination query building
- paginationPagesTotalResolver.go — exported pure page-count rule (PaginationPagesTotalResolver: reject zero page size via ErrItemsPerPageCannotBeZero, count a partial page as a page) usable outside GORM; the builder defers its zero-page-size validation to it so the check lives in one place
- paginationPagesTotalResolver_test.go — tests for the page-count rule
