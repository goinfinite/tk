Infrastructure layer providing repository implementations, database services, and OS/network utility functions. Package name: `tkInfra`.

## Summary

- activityRecord/ — repository implementations for activity record persistence
- db/ — database connection services and query-building utilities
- cypher.go — AES-GCM encryption/decryption with base64-encoded secret keys
- deserializer.go — JSON/YAML file and reader deserialization into maps
- dnsLookup.go — DNS record resolution with configurable resolvers, timeouts, and optional local-resolver bypass (DNSLookupSettings.ShouldBypassLocalResolver issues raw dnsmessage UDP queries for A/AAAA, skipping /etc/hosts and resolv.conf)
- fileClerk.go — filesystem primitives: exclusive creation (WriteNewFile/CopyFile via O_EXCL with exact permission grants), TouchFile (touch(1) contract: refresh timestamps or exclusively create), renameat2 NOREPLACE MoveFile (never replaces a foreign target; same-file move succeeds as a no-op; cross-device falls back to mv(1)-style copy+delete), type-strict DeleteFile/DeleteDir, ReadFileContent capped read failing ErrFileTooLarge instead of silent truncation, CompressFile/DecompressFile sharing one shouldKeepSourceFilePtr contract (tools always keep their input; FileClerk removes it), UpdateFilePermissions chmodding through an O_NOFOLLOW handle (ErrTargetIsSymlink, *os.FileMode param), overwrite-rename [FileClerk.OverwriteFile resolves symlink chains on the target via filepath.EvalSymlinks], FileContentRegex{Search,Replace} follow symlinks with size-based routing at 10MiB and return ErrSourceIsDirectory / ErrTargetIsDirectory / ErrReplacementWouldTruncateFile; sibling temp paths validated via UnixAbsoluteFilePath VO
- readThrough.go — read-through cache pattern for certificate pair file paths (reads from env or generates self-signed)
- serverIpAddress.go — reads the server's private and public IP addresses
- shell.go — subprocess execution with context-deadline timeout, user switching, and environment control (ShouldUseCleanEnv makes the child run from a minimal environment — PATH of the resolved user's ~/.local/bin plus standard system dirs, HOME (parent's for same user, target's home on Username switch), PWD when a working directory is set, DEBIAN_FRONTEND, and explicit Envs — so the parent's other vars cannot leak, independent of Username); also hosts IsStdoutTerminal, the shared CLI interactivity check keeping stdout as the response-only channel
- shellEscape.go — POSIX shell argument escaping
- synthesizer.go — generates random strings, passwords, private keys, and self-signed X.509 certificates
- trustedCidrsReader.go — reads trusted entries from TRUSTED_IPS and TRUSTED_CIDRS env vars; accepts plain IPs (converted to /32 or /128) and CIDR notation; returns []CidrBlock
- *_test.go — tests for each utility

## Constraints

- MUST depend on domain layer, never on presentation layer.
