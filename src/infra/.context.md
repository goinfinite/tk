Infrastructure layer providing repository implementations, database services, and OS/network utility functions. Package name: `tkInfra`.

## Summary

- activityRecord/ — repository implementations for activity record persistence
- db/ — database connection services and query-building utilities
- cypher.go — AES-GCM encryption/decryption with base64-encoded secret keys
- deserializer.go — JSON/YAML file and reader deserialization into maps
- dnsLookup.go — DNS record resolution with configurable resolvers, timeouts, and optional local-resolver bypass
- fileClerk.go — filesystem primitives: exclusive create, atomic move/upsert, copy, compress, permissions, and symlink-safe directory-chain verification
- readThrough.go — read-through cache for certificate pair file paths (env or self-signed)
- serverIpAddress.go — reads the server's private and public IP addresses; resolver endpoints are tried in crypto-random order
- shell.go — subprocess execution with timeout control, user switching by Username or UserId, and clean-environment support; IsStdoutTerminal keeps stdout as the response-only channel
- shellEscape.go — POSIX shell argument escaping
- synthesizer.go — random integers, strings, passwords, private keys, and self-signed X.509 certificates; every draw uses crypto/rand
- trustedCidrsReader.go — reads TRUSTED_IPS and TRUSTED_CIDRS into []CidrBlock
- *_test.go — tests for each utility

## Constraints

- MUST depend on domain layer, never on presentation layer.
