Immutable value objects that enforce domain constraints through validation. Each file defines a single type (e.g., `type IpAddress string`) with a `New*` constructor that validates input. Types span networking, identity, filesystem, X.509/PKI, pagination, catalog, scheduling, and general-purpose values.

## Summary

- util/ — helper functions for value object constructors (type conversion, regex extraction, string normalization, string truncation)
- *.go — one value object type per file, with constructor and optional methods
- *_test.go — table-driven tests for each value object's validation rules

## Constraints

- MUST validate all constraints in the `New*` constructor.
- MUST NOT contain business logic beyond validation.

## Guidance

- SHOULD use `tkVoUtil.InterfaceTo*` helpers for input type conversion in constructors. Assert `string` directly when the constructor must preserve the input exactly.
- SHOULD declare regexes as package-level vars above the type, and use `any` instead of `interface{}`.
- SHOULD reject fractional floats in integer-domain constructors with `tkVoUtil.IsFractionalFloat` before conversion. `NewUnixTime` is the exception: it truncates with `tkVoUtil.TruncateFloat`, so `TimeParamsParser` does not drop a fractional time param.
- SHOULD follow the naming pattern: error messages as `{TypeName}{Constraint}` (e.g., "IpAddressCannotBeEmpty").
