General helper functions for value object constructors and any other layer: type conversion, regex extraction, string normalization, string truncation, and multi-target error matching. Package name: `tkVoUtil`.

## Summary

- interfaceTo.go — converts `any` values to specific Go types (string, int, uint, float, bool, slices, etc.), checks float integrality, and truncates floats
- interfaceTo_test.go — tests for type conversion functions
- isAnyError.go — reports whether an error matches any target through `errors.Is`
- isAnyError_test.go — tests for multi-target error matching
- namedGroupsExtractor.go — extracts named capture groups from regex matches into a map
- namedGroupsExtractor_test.go — tests for named groups extraction
- stringNormalizer.go — normalizes strings (trim, lowercase, remove extra whitespace, etc.)
- stringNormalizer_test.go — tests for string normalization
- stringTruncator.go — truncates strings at a UTF-8 rune boundary
- stringTruncator_test.go — tests for rune-boundary truncation
