Presentation layer providing HTTP request/response helpers, input parsing, and middleware for API and CLI applications. Package name: `tkPresentation`.

## Summary

- README.md — presentation layer component catalog with usage snippets
- middleware/ — request processing middleware (error status mapping, logging, panic handling)
- envsInspector.go — loads .env, validates required vars, and auto-fills missing auto-fillable vars with generated secret keys
- fieldMatchPatternsParser.go — parses semicolon-separated field:pattern pairs into a map of MatchPattern value objects keyed by QueryFieldName
- paginationDtoParser.go — parses pagination parameters from untrusted input maps into Pagination DTOs; rejects a zero itemsPerPage and fractional pageNumber/itemsPerPage
- paginationQueryParamsInputReader.go — reads unprefixed pagination query params and caller-listed optional params into the untrusted input map for PaginationDtoParser; drops values that fail their tk conversion and writes no defaults
- apiRequestInputReader.go — ApiRequestInputReader reads and merges HTTP request input from path params, query params, and body (JSON/form), grouping uploads under `files`
- uiRequestInputReader.go — reads DataTable/Carousel filters by Key/QueryParamName (scalar, multi, range), composes PaginationQueryParamsInputReader, copies BaseInput shallowly, and injects operator context from the Echo context; a missing operator IP address falls back to requester IP extraction
- requesterIpExtractor.go — extracts the requester IP; an untrusted `RemoteAddr` is returned directly, else it checks the optional `IP_EXTRACT_CONFIRMATION_HEADERS` gate, walks the `IP_EXTRACT_HEADER` chain right-to-left, and returns the nearest untrusted entry, the original requester when all entries are trusted, or `RemoteAddr`
- requiredParamsInspector.go — checks that all required parameters are present in an input map
- responseWrappers.go — API and CLI response formatting (`ApiResponseWrapper`, `LiaisonCliResponseRenderer`, `SimpleCliResponseRenderer`) mapping each status to HTTP and sysexits codes
- stringSliceVoParser.go — generic parser converting raw input into typed value object slices
- timeParamsParser.go — parses optional time parameters from untrusted input into UnixTime pointers
- *_test.go — tests for each component

## Constraints

- MUST validate all untrusted input before passing to domain layer.
- UiRequestInputReader MUST inject operatorAccountId from the Echo context and fail with OperatorAccountIdNotFound when it is missing or wrong-type; query-supplied operator fields are overwritten.
- UiRequestInputReader reads filters by Key/QueryParamName with scalar, multi-select, and range kinds; it has no component prefix and no DTO reflection.
- UiRequestInputReader composes PaginationQueryParamsInputReader and leaves pagination defaults to the liaison factory.
